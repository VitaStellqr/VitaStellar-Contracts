# Security Policy & Vulnerability Disclosure

## Supported Versions
Active smart contracts deployed on Stellar Mainnet and Testnet.

## Reporting a Vulnerability
If you discover a security issue or invariant violation:
1. **GitHub Private Vulnerability Reporting**: Submit directly via [GitHub Security Advisories](https://github.com/vitastellqr/vitastellar-contracts/security/advisories/new).
2. **Encrypted Security Email**: `security@vitastellar-protocol.org`.
3. **PGP Fingerprint**: `F82A 9102 384A B12C 9481 2049 B123 4810`.

Please include contract name, minimal reproduction test, and severity evaluation.
